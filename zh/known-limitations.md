我们故意记录哪些不起作用。如果您在这里遇到了某些问题，那么这并不是代码中的错误。这是一个已知的差距。有关发布阶段和路线图，请参阅[可用性和路线图](/docs/availability)；本页列出了您今天可以遇到的具体差距和陷阱。

> **注意**
>
> 最后更新：2026 年 10 月 11 日。我们在每次发布时都会更新此页面。

## 沙箱 `Public V1`

- **可用性由目录驱动**。仅当模板目录和租户策略允许时，才可以选择命名大小，包括 `xs`。已发布的合同并不能保证每个环境中的即时容量。
- **默认值为 `small`**。它解析为 2 个 vCPU、4096 MiB RAM 和 10240 MiB 磁盘。原始 CPU、内存和磁盘字段必须与已发布的合约完全精确匹配。
- **超时是有限的**。 `timeout_sec` 默认为 3600，最大值为 86400。扩展端点替换超时而不是添加持续时间。 `always_on` 取决于策略。
- **使用可能不完整**。活动 CPU 和网络值可以是 `null`，其中 `measurement_status` 设置为 `unavailable`，或保留状态 `stale`。客户端不得将不可用的值视为零或将过时的值视为当前值。
- **支持快照**。公共 V1 包括客户管理的快照创建、列出、显示、删除和恢复（`/sandboxes/{id}/snapshots` 和 `/sandboxes/{id}/restore/{snap_id}`），以及暂停、恢复和分叉。
- **AWS BYOC 沙箱容量是封闭的私有预览**。托管和启用的 BYOC 环境共享沙盒合同，但在接受客户环境之前，BYOC 放置不可用。
- **没有 GPU 沙箱**。公共沙箱创建合约不接受、持久或调度 GPU 请求； GPU 运行时基础设施存在于功能标志后面，但未产品化，并且不收取 GPU 费率。
- **无嵌套虚拟化**。 KVM 和 QEMU 无法在沙箱内运行。

## 部署 `Phase 3/4 complete; dynamic runtime in hardening`

- **自定义域顶点记录需要 ALIAS / ANAME**。不支持扁平化的 DNS 提供商（例如 GoDaddy）需要解决方法。
- **尚无边缘功能**。仅原始计算可用。
- **回滚是按部署进行的，而不是按路由进行的**。您无法在同一部署中将一个 URL 路径固定到版本 1，而将另一个 URL 路径固定到版本 2。
- **容器化部署通过 Docker Host 发布**。每个沙箱都为 Docker 提供了 `docker compose` 和 `docker buildx` 插件，因此您可以在其中构建和测试容器映像。容器化应用程序的持久部署是通过 [Docker Host](/docs/docker-host/docker-deploy) 发布的；标准运行时构建器从源代码构建，不会将 OCI 映像构建到部署中。
- **Railpack / Nixpacks 框架检测** 存在，但构建包的动态生成尚未完成。
- **Docker Host 是一个单独的运行时路径**。它发布到工作区 Docker Host 设备中，并通过 `docker_deploy_app` 行、容器路由、主机运行状况和公共 URL 证明准备情况。标准 MIOSA 部署和 Docker Host 部署共享部署 API 表面，但它们不使用相同的运行时底层。

## 数据服务

- **托管 Postgres** `Beta`。存在供应生命周期和凭证注入。 PgBouncer 连接池和离线备份练习正在进行中。
- **Redis** `Beta`。仅单节点。计划进行多区域复制。
- **对象存储** `Beta`。兼容 S3 的 API 已上线；预签名浏览器上传工作。 CDN 分发和异地复制部署正在进行中。
- **身份验证即服务** `Beta`。每个项目的电子邮件/密码注册、登录、JWT 验证、密码重置和电子邮件确认端点均已上线。刷新令牌、魔术链接、OAuth 提供程序、MFA 和密钥仍在计划中。
- **卷** `Beta`。可以创建持久本地后端卷、将其附加到计算机、分离、删除和计量。本地卷位于一台主机上，因此跨主机附加会返回错误，而不是自动移动卷。
- **按 `external_workspace_id`** 分组的使用/审核查询视图没有 API 视图。存在原始审核事件；在您自己的代码中将它们聚合到每个工作区。

## 计算机（台式机）`GA`

- **仅有头**：计算机没有无头模式。您启动一个真正的 Xfce 桌面。对于无头工作负载，请使用沙箱。
- 默认情况下，**浏览器 cookie 不会在会话中持续**。使用卷安装或浏览器配置文件快照在重新启动时携带 cookie。
- **无多显示器虚拟化**。单个 1920 × 1080 帧缓冲区。
- **音频未公开**。该流仅限视频；系统音频在主机处被丢弃。

## 计算机使用 API

- **无托管智能体循环**。您携带自己的智能体（Anthropic SDK、OpenAI 计算机使用 API 或自定义）。当托管的最佳会话端点公开可用时，将提供内置的 `computer.prompt()` 便利。
- **服务器端不强制执行审批门控**。批准/拒绝操作协议只是客户端约定。在您自己的智能体代码中控制敏感操作。
- **计算机子资源**（auto_stop、vnc_credentials、apps、stream_token、metrics、ports、volume Attach/detach、clone）在 Python SDK 中具有完整覆盖。 TypeScript、Go 和 Java 的对等目标是在 2026 年第三季度实现。

- **部署证明奇偶校验仍然不平衡**。 CLI、TypeScript SDK、Python SDK 和 Go SDK 公开了证明检查。 Java 和 Elixir 证明助手仍在等待中。
- **`embeddings`、`provider_defaults`、`benchmarks`、`command_center`、`community`、`email`、`builder_sessions`、`snapshots_standalone`** 目前仅支持 Python。其他 SDK 语言正在等待中。
- **Python 同步客户端使用长轮询回退**来处理流事件。使用异步客户端或 TypeScript SDK 来实现正确的 SSE。
- **选项卡同步语言首选项** 保留在 `localStorage` 中，而不是您的用户帐户中。在一台设备上切换语言不会传播到另一台设备上。

## API

- **没有 GraphQL 端点**。 REST + SSE 的设计。
- **Webhook 传送重试运行大约 15.5 小时（24 小时窗口内）**。八次尝试后，该事件被删除。使用审核日志回填错过的事件。
- **速率限制**：按层每个 API 密钥每分钟 60 至 30,000 个请求，开发人员/业务/企业上每个工作区每分钟 2,500/25,000/100,000 个请求。可根据要求提供更高的限制。
- **浏览器令牌的默认 TTL 为 1 小时**（60 秒到 7 天）。服务器端刷新；不要尝试客户端扩展。
- **每个浏览器令牌一个沙箱**。单个令牌不能跨多个沙箱。

## 定价和计费

- **尚无每租户使用预算**。您今天设定了工作空间上限；与 `external_workspace_id` 相关的租户级上限随计费归因扩展一起推出。
- **所有流量均根据账户今天的可消费信用余额计费**。有关测试模式密钥，请参阅[可用性和路线图](/docs/availability)。

## 可观察性

- **跨工作区没有本机日志聚合**。今天查询每个资源。
- **尚无 OTLP 跟踪导出**。 `/events` SSE 流提供原始事件；带上你自己的收藏家。
