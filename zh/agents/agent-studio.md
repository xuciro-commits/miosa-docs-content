Agent Studio 是使用已保存智能体的聊天优先方式。
聊天区是主要表面，画布可折叠成细长条，您可以重新打开。

## 每个聊天一个沙箱

一次聊天会得到一个温暖的沙箱，后续的对话会重复使用它。
暂停的沙箱及其文件将被唤醒。
只有被破坏的沙箱才会被替换，聊天里也是这么说的。

## 诚实的状态和错误

状态行显示正在发生的事情：启动沙箱、启动智能体、思考。
失败的消息显示平台自己的消息、其代码和一个提示，在回合中显示一次。

## 工作区面板

工作区面板位于聊天旁边，具有与“最佳”相同的选项卡：

- 预览
- 文件
- 代码
- 终端
- 机器
- 日志

它在聊天的第一个活动中打开并显示聊天自己的沙箱。

## 干净的对话

诸如 Overdrive 警告和标准输入横幅之类的利用措辞永远不会到达聊天中。
Overdrive 是作曲家旁边一个安静的芯片，带有工具提示。
工具行保留在聊天中：长参数不能再扩大它，并且命令、参数和 JSON 输出是可读的。

每个客服人员过去的聊天记录都保存在 Agent Studio 和客服人员页面中。
