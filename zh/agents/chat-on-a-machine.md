打开一台计算机或沙箱的智能体部分，会打开绑定到该计算机的一个聊天。
工作区面板位于它旁边。

## 在聊天中挑选大脑

在发送第一条消息之前，您选择聊天的动力：

- **最佳**使用钱包积分运行机器绑定聊天。
- **工具**在您自己的帐户上运行：Claude Code、Codex、OSA、pi、OpenCode、Prime Agent、Kimi Code 或 Mistral Vibe。
- **保存的智能体**使用自己的指令、工具和权限运行。

聊天与您打开的机器绑定，因此不存在“您应该在哪里构建？”的问题。步。

每个人、每个工作空间和每台机器的大脑都会被记住。
它永远不会改变您在[最佳](/docs/optimal)页面上选择的大脑。

## 当它有效时

- 切换大脑会停止运行，将旧线程保持在分隔线上方，并启动新线程。
- 当您的帐户未连接时，将打开连接卡。
- 批准显示为内联，您可以批准或拒绝。
- **停止**取消运行。
- **将**控制权交给您，然后**交还**将其归还。

## 面板跟随机器

工作区面板在计算机的桌面上打开，在沙箱的终端上打开，然后在 URL 存在后预览。
当您离开时，它会恢复您在“最佳”页面上的布局。

属于另一个工作区的计算机永远不会获得聊天、聊天 ID 或运行。
