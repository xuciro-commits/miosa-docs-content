简短的答案，按主题分组，每个答案都有完整页面的链接。

- [入门](/docs/faq/getting-started)：从哪里开始，如何进行身份验证，安装 CLI，获取 API 密钥，将 ID 附加到沙箱，以及选择区域。
- [沙箱和计算机](/docs/faq/sandboxes-and-computers)：沙箱与计算机、默认沙箱、运行长度、状态、暂停和快照。
- [智能体](/docs/faq/agents)：支持的工具、创建和运行智能体、OSA、模型密钥以及智能体运行的位置。
- [浏览器和计算机使用](/docs/faq/browser-and-computer-use)：浏览器自动化运行的位置、启动浏览器返回的内容、CDP、实时接管和计费。
- [定价和限制](/docs/faq/pricing-and-limits)：您需要支付的费用、暂停的费用、指定尺寸、硬上限、速率限制和积分。
- [安全性和合规性](/docs/faq/security-and-compliance)：SOC 2、HIPAA、数据所在位置、机密存储方式、保留和可发布密钥。
- [白标和平台构建者](/docs/faq/white-label)：白标架构、品牌 URL、最终用户身份验证、向客户计费和品牌。
- [商业操作系统和内部使用](/docs/faq/business-os)：在 MIOSA、连接器、设备选择和平台清单上运行您自己的公司。
- [SOMA 和运行时](/docs/faq/runtimes)：SOMA 是什么、默认运行时、如何选择一个、访问请求和可用性。
- [支持](/docs/faq/support)：如何获取帮助、请求中包含的内容、状态和更改以及社区。
