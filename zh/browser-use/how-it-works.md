## 你得到什么

- **实时浏览器**：在任何正在运行的沙箱中启动它，并在沙箱页面上实时观看页面渲染。
- **控制**：查看者可以控制并直接使用浏览器，或共享可撤销的仅供查看的链接。
- **通过 CDP 进行智能体访问**：Playwright和 Puppeteer 通过 CDP 连接并驱动观众正在观看的同一浏览器。
- **沙盒定价**：它在您已有的沙盒内运行，因此它按普通沙盒使用计费。

## 它如何组合在一起

- **开始。** 要求沙箱启动其浏览器。它在第一个请求时延迟启动，在暂停和恢复期间保持运行状态，并在您停止时停止。
- **观看并驾驶。** 沙盒页面显示实时浏览器。观众可以掌控一切；仅供查看的链接可以观看但不能驱动。
- **自动化。** Playwright 或 Puppeteer 通过 CDP 连接到实时浏览器，并在人们看到的同一会话上进行操作。

由于查看器和自动化共享一个浏览器，因此用户可以在运行中打开页面、观看并进行控制，而不会丢失 cookie、登录信息或页面状态。

## 一个浏览器的三个查看者

|表面|谁 |他们能做什么|
|---|---|---|
|沙盒页面上的实时查看器 |已登录的所有者 |观察浏览器，掌控一切 |
|仅供查看的分享链接 |任何知道链接的人 |仅供观看；无法驱动浏览器|
| CDP端点|特工（Playwright、Puppeteer）|通过 Chrome DevTools 协议驱动浏览器 |

> **注意：仅查看意味着仅查看**
>
> 只能查看的共享链接无法键入、单击或导航。输入在沙盒中的浏览器进程内部被拒绝，而不仅仅是隐藏在 UI 中。

> **注意：一切都通过 api.miosa.ai**
>
> 两个套接字 - 实时视图流和 CDP 端点 - 均位于 `api.miosa.ai` 上，并具有正常的 API 身份验证。
> 沙箱自己的主机或模板端口上没有暴露任何内容。
