## 可用性

浏览器的使用可在任何模板上的每个正在运行的沙箱上使用。
今天有一个例外：SOMA 沙箱附带了 Docker 和 Chromium，但不包含实时查看器渲染的虚拟显示，因此实时查看器在 SOMA 上尚不可用。
浏览器在第一个 `POST /browser` 上延迟启动，因此从不使用它的沙箱无需支付任何费用，并且启动速度与以前一样快。

沙盒映像必须包含 Chromium 系列浏览器和 Node.js。
每个 MIOSA 沙箱镜像都会附带它们；删除它们的自定义图像返回 `501 BROWSER_NOT_AVAILABLE`。

使用浏览器不需要发布模板：守护进程随控制平面一起提供，并在启动时写入每个可启动模板的沙箱中。

## 尺寸

真正的 Chromium 需要空间。为了获得舒适的浏览器，建议使用 `small`（2 vCPU，4 GB）或更大。

|尺寸| vCPU |内存 |浏览器使用|
|---|---|---|---|
| `xs` | 1 | 2GB|紧的;最多一个光页 |
| `small` | 2 | 4GB| **建议最低限度** |
| `medium` | 4 | 8GB|舒适|
| `large` | 8 | 16GB|厚页和并行选项卡 |

## 生命周期

|行动|对浏览器的影响|
|---|---|
| `POST /browser` |延迟启动浏览器（幂等）|
|暂停沙箱 |浏览器状态被保留；会话在恢复后继续存在|
|简历沙箱 |同一个浏览器又回来了，带有选项卡和登录名|
| `DELETE /browser` |停止浏览器并释放其内存；沙箱继续运行|
|摧毁沙盒 |删除所有内容，包括浏览器状态 |

暂停和恢复保持浏览器；停止浏览器会释放其内存。

## 保存的网站登录信息

该平台存储一个人保存的网站登录信息，以便沙盒浏览器可以填充它们，而智能体不会看到密码。
`GET /api/v1/signins` 列出它们，`PUT /api/v1/signins/{site}` 保存一个，`DELETE /api/v1/signins/{site}` 删除一个。
发送`workspace_id`；没有它的请求会回答 `422 WORKSPACE_REQUIRED`。
响应被屏蔽：它们带有用户名预览和 `last_used_at`，而不是密码。
`POST /api/v1/sandboxes/{id}/browser/signin` 和 `{"site": "..."}` 将保存的登录信息填充到打开的选项卡中，仅在您自己运行的沙箱上且仅在该站点的 HTTPS 页面上。

浏览器也是沙箱内的一个进程，因此如果沙箱重新启动，浏览器也必须重新启动。 `GET /browser` 报告当前状态（`running`、`stopped`、`unavailable` 或 `sandbox_not_running`），而不启动任何内容。

## 计费

浏览器将账单用作**普通沙箱使用**。
没有单独的浏览器行项目：当沙箱运行时，您需要支付已经为该大小支付的沙箱费率，并且浏览器在其中运行。
停止浏览器会释放内存，但本身不会停止沙箱。

## 安全

- 没有任何事情被公开曝光。两个套接字（实时视图流和 CDP 端点）都通过 `api.miosa.ai` 进行正常的 API 身份验证，而不是通过沙箱自己的主机。
- 控制平面仅在沙箱的环回上连接到浏览器守护程序，并每次向其提供 60 秒的令牌。调用者永远不会看到该令牌。
- 套接字上的 **API 密钥需要 `sandboxes:exec`**，因为浏览器可以访问沙箱可以访问的任何内容。
- 共享代币**仅供查看**。他们的输入在沙箱的浏览器进程中被拒绝，而不仅仅是隐藏在 UI 中。
- 共享链接是**可撤销的**：通过 `share_id` 撤销一个链接，或一次撤销每个共享和 CDP 链接。撤销会影响浏览器的共享纪元，因此未完成的链接会立即停止工作。
- 实时视图和 CDP 套接字共享每个租户的流限制；超过它会使用 `4013` 关闭套接字。

> **警告：切勿暴露 API 密钥**
>
> 后端的 Mint 查看器和 CDP 访问权限。
> 仅向浏览器或智能体发送短暂的 `stream_auth` 令牌或共享链接。
> 切勿将 MIOSA API 密钥发送到前端。
