大脑是回答聊天的人。
在第一条消息之前，在作曲家的大脑选择器中选择它（工具提示“选择谁回答”）。

## 三种大脑

|大脑 |帐单至 |它在哪里运行 |最适合 |
|---|---|---|---|
| **最佳** |钱包积分 | MIOSA，通过范围内的工具在您的机器上工作 |有关您的工作空间、建筑、调查的问题 |
| **运行框架** |您自己的模型帐户 |在您选择的沙箱或计算机上|使用 Claude Code、Codex、OSA 等进行编码 |
| **已保存的智能体** |您自己的模型帐户 |在您选择的沙箱或计算机上|拥有您自己的指令、工具和权限的智能体 |

## 最优

最佳模型是 MIOSA 内置的模型。
选择器将其显示为“内置于 MIOSA”和“使用您的钱包积分”，并在其下方显示实时价格。

- 这是一个模型，具有 1M 代币上下文。
- 您不能为其选择不同的型号，并且它不使用您自己的型号密钥。
- 它是唯一提供调查模式的大脑。

在没有剩余积分的免费计划中，选择器中通过“添加积分以使用最佳”禁用最佳。

## 运行框架

运行框架是一种编码智能体，可以在您自己的帐户的计算机上运行。
MIOSA 积分永远不会为其模型付费。
选择器在**您的智能体**下列出了运行框架：

- 克劳德法典、法典和 OSA；
- OpenCode、pi、Prime Agent、Kimi Code、Mistral Vibe 和 Hermes（当您的组织可以连接它们时）。

每行显示其连接状态：与帐户“已连接”、“未连接”或“需要再次登录”。
**连接** 或 **重新连接** 打开该运行框架的登录，然后返回到“最佳”状态。
请参阅 [Harnesses and auth](/docs/agents/harnesses) 了解每个 Harnesses 接受的内容。

在任何模式下，运行框架总是询问在哪里工作，因为每条消息都是在机器上运行。
成本条显示该工作按您自己的计划计费。

## 已保存的智能体

保存的智能体是您在 Agent Studio 中构建的智能体，具有自己的指令、工具、模型、工具和权限。
已保存的智能体显示在他们使用的运行框架旁边的**您的智能体**下。
未列出已存档的智能体。

要构建一个，请选择大脑选择器底部的 **构建智能体**，或打开 [Agent Studio](/docs/agents/agent-studio)。
从 CLI：

```bash
miosa agent new reviewer --harness claude-code --instructions-file review.md
miosa agent list
```

## 切换大脑

大脑在收到第一条信息后就固定下来了。
然后选择器的工具提示显示“此聊天保留其大脑。开始一个新的聊天以更改它。”
在已开始的聊天中选择另一个大脑会开始新的聊天。

> **注意：您的钥匙归您所有**
>
> 运行框架和保存的智能体在您自己的模型帐户上运行。
> Optimal 的型号是 MIOSA 的，并且仅以钱包积分支付。
