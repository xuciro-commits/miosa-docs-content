每个 MIOSA 数据均来自其实时定价 API 及其公布的每个尺寸的价格。
每个竞争对手的数据均来自供应商自己的定价页面，检查**2026-10-20**，来源列在最后。

有关功能和测量的性能，请参阅[MIOSA 与其他平台](/docs/compare)。

## 计算成本，标准化

到处都是同一个盒子：**4 vCPU / 8 GiB RAM，每小时运行**，根据每个供应商公布的单位费率计算。
MIOSA 数据来自实时定价 API (`GET /api/v1/pricing`)：每种大小都有一个小时价格，4 vCPU / 8 GiB 大小为 0.1785 美元。

|供应商| vCPU 速率 |内存速率| **4 个 vCPU + 8 GiB/小时** |
|---|---|---|---|
| **MIOSA** | $0.027216 / vCPU 小时 | $0.0087075 / GiB-小时 | **0.1785 美元**（仅计算；磁盘和出口单独计量）|
| **Railway** | $0.02779 / vCPU 小时 | $0.01389 / GiB-小时 | **~$0.22** |
| **自由式** | $0.04032 / vCPU-小时 | $0.0129 / GiB-小时 | **~$0.26** |
| **E2B** | $0.0504 / vCPU-小时 | $0.0162 / GiB-小时 | **~$0.33**（专业版+$150/月）|
| **Vercel 沙箱** | $0.128 / 活动 vCPU 小时 | $0.0212 / GB-小时 | **~$0.68**（仅限活动 CPU）|

> **注意**
>
> 这些是仅运行计算的标价，并且它们会变化。
> MIOSA 还可以计量磁盘和网络出口；一些提供商对存储、出口和更高的多区域费率进行计费。
> Vercel 仅在 CPU 处于活动状态时对其进行计费。
> 在下面的计算器中调整您关心的形状的大小。

## MIOSA 最适合的地方

- **每种大小一个价格**：每个 MIOSA 计划按大小支付相同的每小时价格，加上相同的磁盘和出口费率；计划仅更改上限和并发性。开发者硬停在 0 美元余额。
- **沙箱、计算机和部署**在一个 API 上，为您自己的客户提供[白标品牌](/docs/platform/white-label)。
- **带上您自己的硬件或云**：[OpenComputers](/docs/opencomputers) 和 [带您自己的云](/docs/infrastructure/byoc/overview)。
- **功能和测量的性能**：请参阅[MIOSA 与其他平台对比](/docs/compare) 和[基准](/docs/benchmarks)。
