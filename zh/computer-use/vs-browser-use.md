两者都驱动真正的浏览器。它们的不同之处在于您租用的机器数量。

> **Note: The rule**
>
> 如果任务是智能体或个人应该观看的网页，请使用 [浏览器使用](/docs/browser-use) - 它在任何沙箱中运行，并按照普通沙箱使用情况计费。
> 如果任务需要完整桌面、其他应用程序或接管整个屏幕，请使用[计算机使用](/docs/computer-use)。

| |浏览器使用|电脑使用|
|---|---|---|
| What runs |沙箱内的实时浏览器 |计算机上的完整 Linux 桌面 |
|哪里 |任何沙箱，任何模板|您创建并启动的计算机|
|设置 | On by default;创建时无需选择|创建计算机，然后启动它 |

|人类接管| The browser view | The whole desktop |
| Other apps |否 - 仅浏览器 |是的 - 任何已安装的 Linux 应用程序 |
| Persistence |保留暂停和恢复 |经受停止和启动|
|计费| Plain sandbox usage |计算机在运行时进行计算 |
|最适合 |值得关注的 Web 自动化、抓取、登录浏览器工作 | GUI 应用程序、桌面工作流程、屏幕截图 QA、全人工切换 |

## 选择浏览器使用时间

- 该任务完全存在于网页上。
- 您想要最便宜的隔离环境：您已经用于代码的沙箱。
- 一个人应该能够观看、控制或共享仅供查看的链接。
- Playwright或Puppeteer是你的司机。

## 选择计算机使用时间

- 该任务需要桌面应用程序、文件选择器、扩展程序或多个窗口。
- 智能体根据整个屏幕上的像素和可访问性树进行工作。
- 人类必须接管特工正在使用的机器。
- 您需要一个耐用的桌面，可以在重新启动后保留其浏览器配置文件和已安装的工具。
